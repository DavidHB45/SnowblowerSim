# Licenses and attribution

One row per third-party asset that ships in the game (anything under `unity/Assets/ThirdParty/`
or bought for a machine tier). Add the row when the asset is added to
`unity/Assets/ThirdParty/manifest.json` or first used in a scene. The matching
`<id>.license.txt` beside the files is the source of truth for the license. This table is what the
credits screen and store page are built from.

- **License:** `CC0`, `CC-BY 4.0`, or the paid license name (e.g. `TurboSquid Standard`). No NC/ND.
- **Attribution required:** `Y` for CC-BY and any license that asks for credit; paste the exact
  credit line into the next column. `N` for CC0 (crediting CC0 authors is still welcome).
- **Where used:** environment(s), level(s), or machine tier, e.g. `Suburban L1–L7`, `Two-stage blower`.
